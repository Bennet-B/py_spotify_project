# INFPROG2 FS26: Semester Project Guide

Alternative to Weekly Praktikum!

## Overview

Instead of earning points through weekly Praktikum assignments (P01-P05), you may choose to complete a semester-long project. The project replaces all Praktikum points (20% of the final grade, max 20 points). Teams of 1 or 2 students.

The goal is to build a working Python application that retrieves, processes, and analyzes real-world data. The topic is your choice, but it must be related to Data Science in a broad sense and must demonstrate the programming competencies taught in this course.

You are explicitly allowed and encouraged to use AI-assisted development tools (Cursor, Antigravity, GitHub Copilot, etc.) as part of your workflow. However, you must be able to explain every line of your code during the final presentation. Blind copy-paste from AI without understanding will result in small amount of points.

## Required Technical Components

Your project must incorporate the following elements, which correspond directly to the INFPROG2 lecture topics:

1. Object-oriented design (V02 to V04). Structure your application using classes with meaningful inheritance where appropriate. At minimum: 2 to 3 classes with constructors, attributes, and methods.
2. Internet data access (V05). Fetch data programmatically from at least one public API or web data source using urllib or similar. No manual CSV downloads as the primary data source.
3. Robustness and validation (V06). Handle network failures gracefully (try/except, retries). Validate and sanitize input data. The application must not crash on malformed or missing data.
4. Data processing with Pandas (V07 to V09). Use Pandas DataFrames for storage, filtering, aggregation, or transformation of retrieved data. Produce at least one visualization (plot, chart).
5. Code quality (V10 to V13). Include at least 3 meaningful unit tests. Be aware of algorithmic complexity in your data processing (no accidentally quadratic loops on large data).

## Deliverables

Submit a single Git repository (GitHub, GitLab, etc.) containing:

- Source code in a clean structure (e.g. src/, notebooks/, tests/).
- A README with: project description (2 to 3 sentences), how to install dependencies and run it, brief explanation of what each module does.
- A short Jupyter notebook or script demonstrating the application in action (fetching data, processing, producing output).

## Presentation

In the last lab session of the semester, each team gives a short presentation (5 to 10 minutes) demonstrating the working application and answering questions about the code. Both team members must be able to explain any part of the codebase.

## Grading

| Criterion | Points |
| --- | --- |
| OOP design (classes, inheritance, encapsulation) | 4 |
| Internet data access (API calls, robustness) | 4 |
| Data processing and analysis (Pandas, visualization) | 4 |
| Code quality (tests, structure, readability) | 4 |
| Presentation and ability to explain the code | 4 |
| **Total** | **20** |

Each criterion is graded 0 to 4: 0 = missing, 1 = minimal attempt, 2 = partially working, 3 = functional with minor issues, 4 = solid implementation.

## Example Project Directions

These are suggestions to give you a starting point. You are free to propose your own topic.

**Weather analysis tool.** Fetch weather data from Open-Meteo API (no key required) for multiple Swiss cities. Store historical data in DataFrames, compute statistics (mean temperature per month, precipitation trends), visualize seasonal patterns. Classes: WeatherStation, DataCollector, Analyzer.

**Public transport delay tracker.** Use the [transport.opendata.ch](http://transport.opendata.ch/) API to query real-time departures at selected stations. Collect delay data over time (or use historical data), aggregate by line/time-of-day, identify patterns. Classes: Station, DepartureMonitor, DelayAnalyzer.

**News or job market monitor.** Fetch structured data from a public API (e.g. Hacker News, job listings, Reddit). Filter and categorize entries by keywords, compute frequency statistics, visualize trends over time. Classes: DataSource, Classifier, Report.

**Swiss open data explorer.** Pick a dataset from opendata.swiss (e.g. energy, demographics, education). Build a pipeline that downloads, caches, cleans, and analyzes the data. Produce summary statistics and at least two different visualizations. Classes: DataPipeline, CacheManager, Visualizer.

**Cryptocurrency or stock tracker.** Fetch price data from a free API (CoinGecko, Yahoo Finance). Compute moving averages, volatility, simple indicators. Visualize price history with annotations. Classes: Asset, PriceFetcher, TechnicalAnalyzer.
